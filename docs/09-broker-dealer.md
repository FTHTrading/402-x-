## Deal path

1. **Originate** — sponsor / asset / mandate  
2. **Structure** — pick RWA family, Studio receipts, custody architecture  
3. **Licensed placement** — when the activity requires a licensed broker-dealer, use one  
4. **BitGo custody** — segregated deal vault / Go Account posture  
5. **Funder** — Cantor Fitzgerald CRE or other firm-level rails  

## What this portal will not do

- Invent CRD/SEC/FINRA registration numbers  
- Treat demo AUC / fee calculators on marketing UIs as audited Unykorn financials  
- Sell brokerage via the Stripe catalog (commerce is software/ops only)
